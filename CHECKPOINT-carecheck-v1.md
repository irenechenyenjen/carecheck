# CareCheck v1 checkpoint

This is the stable text-only version before experimenting with image/video analysis.

Stable behavior:

- English-only older-adult-friendly interface
- Five model-driven result categories:
  - High caution
  - Mostly correct
  - Looks useful
  - Needs checking
  - Unable to verify
- One input box and one repeated `Check this message` action
- Portkey/OpenAI evidence review using the configured `gpt-6-luna` course model
- Oat/ivory, navy, terracotta, and slate visual system
- Calm conversational response wording

If the multimedia experiment becomes unreliable, restore the app to this text-only behavior and preserve this design direction.
